# Sabeer Alam — Developer Portfolio

A responsive single-page portfolio for Sabeer Alam, a MERN Stack Developer and Full Stack Developer.

## Sections

- Hero
- About
- Skills
- Experience
- Featured Projects
- Services
- Education
- Contact

## Featured projects

- **FreelanceHub-PK** — a full-stack freelance work-management platform for clients, projects, budgets, deadlines, and project status.
- **Lumina — SaaS Landing Page** — a responsive React SaaS landing page with theme switching, mobile navigation, and scroll-reveal effects.

## Architecture

- `src/components/` contains section and shared UI components.
- `src/data/` holds project and skills data.
- `src/pages/Home.jsx` composes the page sections.
- `src/hooks/` holds theme and active-navigation hooks.
- `src/utils/` holds shared constants and icons.

## Technology

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run lint
npm run build
```
